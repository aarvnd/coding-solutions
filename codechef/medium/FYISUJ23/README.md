## Problem

### Worked Example - Storing and Displaying Large Num

In this example, we use the `long` data type to store and print a large numerical value.

 **When executed, the code will show** :

```
Total Signals Received: 9876543210  

```

## Solution

**Language:** Java  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-08-14T06:27:10.545Z  

```java
class Codechef {
    public static void main(String[] args) {
        // Declare and assign a large number using long
        long totalSignalsReceived = 9_876_543_210L;  // Total signals from space missions

        // Print the stored value
        System.out.println("Total Signals Received: " + totalSignalsReceived);
    }
}

```
