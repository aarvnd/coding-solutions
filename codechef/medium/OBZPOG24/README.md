## Problem

### Formatting a Poem

A developer wants to print a poem with each line on a new row.

```
class Codechef {
    public static void main(String[] args) {
       System.out.println("Roses are red _____ Violets are blue");
    }
}

```

 **Expected Output** 

```
Roses are red 
Violets are blue

```

## Solution

**Language:** C++  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-08-14T05:51:54.413Z  

```cpp
class Codechef {
    public static void main(String[] args) {
        // Prints the famous movie quote using escape sequences
        // \' is used to include a single quote within the string
        // \" is used to include a double quote within the string
        // \n is used to add a new line
        // \t is used to add a tab space before "- The Shining"
        System.out.println("Here\'s Johnny!\"\n\t- The Shining");
        
    }
}

```
