## Problem

### Printing using a variable

In this program, you need to store the value `18` into a variable and print the message given below.

To combine the variable and the message, we will use the + operator. This lets us print the value stored in the variable along with the string message.

### Expected Output

```
The value stored in variable is 18

```

## Solution

**Language:** Java  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-08-14T06:06:33.171Z  

```java
 class Codechef{
    public static void main(String[] args){
       var value = 18;
       System.out.print("The value stored in variable is " + value);
    }
}

```
